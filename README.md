# lark-toolkit

Modular Python utilities for Lark/Feishu API.

## Install

```bash
# From source (editable)
pip install -e ".[dev]"

# From GitHub
pip install git+https://github.com/carlnoah6/lark-toolkit.git
```

## Development

```bash
pip install -e ".[dev]"
pre-commit install
pytest
ruff check src/ tests/
```
